# Cortical surface visual asset

Derived from the fsaverage5 left and right pial surfaces shipped by Nilearn:
https://github.com/nilearn/nilearn/tree/main/nilearn/datasets/data/fsaverage5

Nilearn BSD license reproduced in LICENSE.txt. Coordinates are centered, uniformly scaled, and reoriented for Three.js. cortex.bin stores two uint32 counts, float32 XYZ vertices, and uint16 triangle indices, all little endian. brainAnchors.json contains 1,024 sampled surface positions.

This surface provides a recognizable brain-shaped visual metaphor only. Software node placement, colors and connections do not claim biological correspondence. No medical data belonging to the portfolio owner is used.
